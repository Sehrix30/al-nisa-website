# Al-Nisa Welfare Society Website

A responsive multi-page website developed as a volunteer project for Al-Nisa Welfare Society, a registered NGO based in Okara, Pakistan.

## Project Overview

The website provides a professional online presence for Al-Nisa Welfare Society and presents its programs, community impact, partnerships, and opportunities to get involved.

## Pages

- Home
- About Us
- Our Programs
- Impact & Partnerships
- Get Involved

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Key Features

- Responsive design
- Mobile navigation
- Accessible semantic HTML
- Image carousels
- Image lightbox
- Responsive layouts
- SEO-friendly page structure
- Descriptive image alt text
- Contact form UI

## Status

The website is currently deployed using GitHub Pages.

The contact form backend is pending the organization's official Web3Forms setup.
